# Mijn Startpagina

Een eigen Chrome-startpagina (nieuw tabblad) met apps, klok en wisselende achtergrond. Versie 5.2.0.

## Installeren op een nieuw apparaat
1. Klik hierboven op de groene knop **Code → Download ZIP** en pak de zip uit op een vaste plek.
2. Ga in Chrome naar `chrome://extensions` en zet rechtsboven **Ontwikkelaarsmodus** aan.
3. Klik op **Uitgepakt laden** en kies de map waarin `manifest.json` staat.
4. Open een nieuw tabblad en kies **Behouden** als Chrome dat vraagt.

## Bijwerken
Download de nieuwste ZIP, vervang de bestanden in je map en klik bij de extensie op `chrome://extensions` op het ronde pijltje. Je apps en instellingen blijven bewaard (die staan in Chrome, niet in deze bestanden).
